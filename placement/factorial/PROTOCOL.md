# Does jointly augmenting four perturbations improve held-out tactile decoding?

The preceding experiment found that the choice of coordinate frame helped with placement but left poor worst-case accuracy under joint perturbation. This follow-up changes the schedule during training. It holds the number of training examples and the marginal strength draws for each perturbation exactly fixed. The comparison estimates the value of exposing interactions under the stated replay distribution. It does not claim a new neural architecture or that a simulator is a physical measurement.

For motion warp (A), sampling and quantization (B), translated contact placement (C) and missing taxels and time interval (D), apply five views per recording. The paired-exposure control uses clean, AB, CD, AC and BD. The joint-exposure treatment uses clean, ABCD, CD, A and B. Each factor occurs twice per trace in each schedule, with independent identical pseudorandom parameter seeds keyed by factor and occurrence. Both arms share labels, dataset split, 121 maximum derivative events, input arrangement, optimizer, hidden width, train batch counts and hyperparameter grids. The choice of grouping necessarily changes order, realistic incidence of destructive interactions and number of surviving training events. This is a test of two schedules, not every possible way to combine matched component doses.

Reuse the same 18/6/10 writer splits and 7,700 STEMNIST raw traces, with three fresh deterministic seed domains. This is an independent synthetic draw within the same writer cohort. No test score from this follow-up informs model selection. For every trace, the shared evaluation list has clean, translation, coarse+missing, all-four with a contiguous dead stripe, and all-four with a localized patch plus a separate dead line. The latter taxel failure geometry does not occur in training. Both arms see exactly the same test events, including after clipping and missing observation. Rates and placement are drawn from the same ranges across training and evaluation. Results concern response under this perturbation family.

Fit the same 64-unit MLP to each of three fixed 512-feature descriptors: fixed-frame rank, extent-aligned elapsed time, and centroid-aligned rank. Select optimizer rate and stop epoch for every arm and feature using the six validation writers and the minimum over both joint conditions, breaking ties with average accuracy. Choose the strongest paired-control feature by this rule. Lock it and compare it to joint exposure using exactly the same descriptor and classifier capacity. Compare their minimum equal-writer accuracy over the two joint conditions, with 12,000 paired writer bootstrap draws over ten held-out writers; recompute the minima in each draw. A positive result requires at least +5 points in the point estimate, with a lower 95% endpoint above zero. Keep the clean-accuracy lower paired 95% endpoint above −2 points. Both gates must pass. Archive all candidate predictions and treat condition-wise differences as descriptive. No additional tuning after scoring.
